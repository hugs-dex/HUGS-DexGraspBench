# Hand assets

This release candidate includes only the Shadow and Leap-SP end-effector MJCF
assets used by the four supported Bench configurations:

- `shadow` and `dual_dummy_arm_shadow`
- `leap_sp` and `dual_dummy_arm_leap_sp`

Object meshes and raw producer assets are external inputs. Before publishing these
robot assets, record their upstream revision and redistribution terms in
`manifest.json`; the repository does not claim a project-wide OSI license.
